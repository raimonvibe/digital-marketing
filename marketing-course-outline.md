# Self-Built Digital Marketing & E-commerce Course

Personal learning course, modeled on Google's Digital Marketing & E-commerce Professional Certificate, expanded with extra modules and tools found in research. Front-end only site, no back end needed — static pages with embedded quizzes and hands-on tool tasks.

The course is designed with a **university-style academic feel** rather than a casual blog: each module follows a consistent structure with stated learning objectives, a lesson, a hands-on tool task, a quiz or assignment, and a summary recap, similar to a real university syllabus. Full academic-element details are listed near the end of this document.

Each tool is taught INSIDE its relevant module as a mini-lesson with this structure:
1. What the tool does and why it matters (short explanation)
2. A concrete hands-on task with the direct link to the tool's free tier
3. A reflection or quiz question applying it to your own business

## Module 2: Attract & Engage Customers (SEO + SEM + Social)

### Lesson: SEO Basics
Explanation: SEO helps your site show up in search results without paying for ads.
Task: Go to Google Search Console at search.google.com/search-console, add your own site (raimonvibe.eu or another project), and check what search terms already bring people to it.
Quiz: What's one keyword you found that surprised you?

### Lesson: Semrush
Explanation: Semrush helps you research keywords and see what competitors rank for.
Task: Go to semrush.com, use the free Keyword Overview tool, and look up a keyword related to static websites or web development.
Quiz: What's the search volume and difficulty for that keyword?

### Lesson: Ahrefs
Explanation: Ahrefs is an alternative SEO tool, especially strong for backlink research.
Task: Go to ahrefs.com/backlink-checker, enter your own site, and see who links to you, if anyone.
Quiz: Did you find any backlinks you didn't know about?

### Lesson: Google Ads (SEM)
Explanation: Paid search ads that appear above organic results.
Task: Go to ads.google.com, explore the Keyword Planner (free, no ad spend required), and search a term related to your services.
Quiz: What's the estimated cost per click for that term?

### Lesson: Google Business Profile
Explanation: Free local listing that shows your business on Google Maps and search.
Task: Go to google.com/business and set up or check your own profile.
Quiz: Is your business currently showing up when you search your own name?

**Quiz topics:** SEO true/false; scenario choosing SEO vs paid ads; match platform to content type

## Tool Icons/Images — Implementation Plan
Instead of manually downloading logos, use **Google's favicon fetcher service** to automatically pull each tool's icon:

Format: `https://www.google.com/s2/favicons?domain=DOMAIN_HERE&sz=64`

Example for Canva: `https://www.google.com/s2/favicons?domain=canva.com&sz=64`

This can be automated: an AI coding agent can loop through the full tool list and generate an `<img>` (or Next.js `<Image>`) tag for each tool automatically using this pattern — no manual logo downloading required.

**Alternative approaches considered:**
2. Google favicon fetcher — fastest, fully automatable, lower visual polish (small icons only)
3. Design custom icons in Canva for each tool — ties into Module 4 (Design), fully original, more time investment

**Decision: use Google favicon fetcher for speed, automated via AI coding agent.**

## UI/UX Ideas to Elevate the Course Site

**Navigation & Layout**
- Collapsible accordion/dropdown menus per module instead of long stacked lists — click a module title to expand its lessons
- Sidebar with progress indicator (checkmarks per completed lesson) even without a backend — use browser localStorage to persist progress per visitor
- Sticky top nav with a progress bar showing percentage through the whole course

**Visual Style**
- Card-based layout for each tool lesson (icon, short blurb, "Start Task" button) rather than plain paragraphs
- Subtle hover animations on cards/buttons for a more polished, alive feel
- Color-code modules by theme (e.g. SEO = green, Design = purple, E-commerce = blue) for quick visual recognition
- Dark mode toggle

**Language & Tone**
- Use active, direct verbs in lesson titles: "Build Your First Email" instead of "Email Marketing Basics"
- Frame tasks as challenges: "Your Mission" instead of "Task"
- Add small motivational microcopy after quiz completion, e.g. "Nice work, on to the next one"

**Interactivity**
- Expandable "why this matters" tooltip/info icon next to each tool, for optional deeper context without cluttering the main flow
- Simple progress badges (icons unlocked) per completed module, purely visual/localStorage-based, no backend needed
- Embed the tool favicon (from the automated favicon fetcher) directly on each module card for quick visual scanning

## Avoiding the "Generic AI Website" Look

Common AI-generated design tells to actively AVOID:
- Purple-to-blue gradient hero with centered white text
- Single font (usually Inter) used for everything, headers and body alike
- Everything perfectly centered — no editorial opinion, no visual anchor
- Gray icon-tile grid with identical boxes and small colored icons
- Standard nav: logo far left, 4 links centered, 1 rounded CTA far right
- Stock-feeling AI generated imagery, or no imagery at all replaced by abstract gradients/shapes

What to do INSTEAD, to make it feel distinctive and personal:
- Pick two contrasting fonts on purpose — one distinctive display font for headings, one clean font for body text (not both Inter)
- Break symmetry deliberately — offset images, asymmetric layouts, let some sections feel editorial rather than templated
- Use a personal color palette tied to Raimonvibe branding rather than a default gradient
- Add small custom illustrations or icons via Canva (ties back into Module 4) instead of generic icon packs
- Consider neobrutalism or a bold/quirky style as an option — thick borders, bold shadows, raw typography — since it reads as intentionally human-made rather than templated
- Write lesson/module titles and microcopy in your own voice rather than default AI-generated phrasing

Practical approach: extract a small "design system" first (colors, font pairing, spacing, corner radius) before building any pages, so every module page stays consistent rather than each one looking randomly different.

## University-Style Academic Elements

Borrowed from real university online-course design standards, to give this a more formal, academic feel rather than a casual blog:

- **Syllabus page** as the course homepage — course description, overall learning objectives, module list with estimated time per module, and how quizzes/tasks work
- **Learning objectives per module** — stated clearly at the top of each module page (e.g. "By the end of this module, you will be able to set up a basic SEO audit for a website")
- **Consistent module structure** — same predictable layout every time (objectives, lesson, tool task, quiz, summary) so it reads as a real course rather than a loose blog
- **Case-study style assignments** — instead of only quizzes, some modules could end with a small project-based assignment (e.g. "Design one full email campaign for a fictional client using what you learned")
- **Module summary/recap section** at the end of each module, reinforcing key takeaways before moving on
- **Glossary page** — collects marketing terms introduced throughout the course (SEO, SEM, funnel, CTA, etc.) in one place, like a university course glossary
